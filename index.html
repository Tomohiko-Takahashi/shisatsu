このファイルのソース内、DBX_ACCESS_TOKEN の値にトークンを貼り付けてから、GitHub Pagesへデプロイしてください。一度設定すれば、メンバーは連携作業なしでそのまま使えます。

  2. Permissions タブで files.content.write と files.content.read にチェック → Submit

  4. 生成されたトークン(sl.xxxx…)をコピーし、ソース内の DBX_ACCESS_TOKEN に貼り付け
