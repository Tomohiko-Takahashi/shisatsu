Dropbox連携の設定

App KeyはDropbox App Consoleの作成済みアプリの設定画面に表示されています。「連携する」を押すとDropboxのログイン画面に移動し、戻ってくると自動で保存されます(この作業は最初の1回だけで大丈夫です)。

Dropboxとの連携が必要です

最初に一度だけ、下の手順でログイン連携してください。連携すると裏側で自動更新される仕組みになるので、以降トークンを手動で発行し直す必要は一切ありません。

  1. Dropbox App Consoleを開き、Create app → Scoped access → App folder を選択してアプリを作成
  2. Permissions タブで files.content.write と files.content.read にチェック → Submit
  3. Settings タブ → OAuth 2 → Redirect URIs に、今このページを開いているURLをそのまま貼り付けて Add
  4. 同じSettingsタブ上部にある App key をコピーし、下の欄に貼り付ける
